# Contributing to MPS Model & System Descriptors

Thank you for helping build PhysioVerse.

## You do not need to write code

Most contributions to this project are scientific, technical, data-curation, standards, protocol, validation, or community contributions.

## Fastest way to contribute

1. Open **Issues**.
2. Click **New issue**.
3. Choose **Make a community contribution**, **Nominate a public resource**, or **Review a working draft**.
4. Complete what you know and submit.

## What makes a strong contribution

- Be specific.
- Include a DOI, accession, publication, repository, protocol, standard, ontology, or other public source when available.
- Explain the MPS context and why the contribution matters.
- Separate evidence from suggestions.
- Do not upload confidential, proprietary, patient-identifiable, or otherwise restricted information.

## More involved contributions

If you want to edit a working document directly, open an issue first or submit a pull request with a focused change. Keep each pull request limited to one clear contribution.

## Questions

If you are unsure where your contribution belongs, open a community contribution issue and describe what you have. A maintainer can help route it.
