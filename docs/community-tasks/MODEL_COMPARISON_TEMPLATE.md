# Source-Linked Model Comparison Template

**Working comparison record. Not a model ranking or a universal quality score.**

[Contribute model descriptors](https://github.com/PhysioVerse-OSE/mps-model-system-descriptors/issues/new?template=community-contribution.yml) · [View project tasks](https://github.com/PhysioVerse-OSE/mps-model-system-descriptors/issues)

Start with a specific biological question or intended use. Complete one record for each model before placing models side by side. Retain the model identity and version from the source. Do not combine different versions into one record without an explicit explanation.

## Compare Only What the Evidence Supports

For each attribute, record whether definitions, units, time origins, biological units, and assay conditions are sufficiently comparable. Where they differ, retain both source values and explain the difference. Do not replace missing values with zero or infer performance from a model label.

A benchmark should retain its metric, reference population or tissue, preprocessing, uncertainty, and applicable context. Do not convert a correlation or distance into a percentage of human biology reproduced. Do not identify a universally best model from this template.

## Community Review

State which comparison questions can be answered, which remain unresolved, and which additional evidence would be useful. Link the related [validation](https://github.com/PhysioVerse-OSE/mps-validation-framework) and [reproducibility](https://github.com/PhysioVerse-OSE/mps-reproducibility-commons) discussions rather than duplicate unsupported conclusions.
